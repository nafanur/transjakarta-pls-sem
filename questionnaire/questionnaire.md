# Research Questionnaire

## Study Topic
PLS-SEM Analysis of the Relationship Between TransJakarta Fare
Increase and Users' Interest in Using TransJakarta

## Measurement Scale
All items were measured using a 4-point rating scale.

| Scale | Description |
|---|---|
| 1 | Strongly Disagree |
| 2 | Disagree |
| 3 | Agree |
| 4 | Strongly Agree |

## Variable 1: TransJakarta Fare Increase
| Code | Statement |
|---|---|
| tarif_1 | I feel that the current TransJakarta fare is affordable. |
| tarif_2 | Based on my experience with TransJakarta services, I do not object to an increase in the TransJakarta fare. |
| tarif_3 | I understand the reasons given by the government and relevant parties regarding the TransJakarta fare increase. |
| tarif_4 | A fare increase is reasonable as long as the fare remains competitive compared with other modes of transportation. |
| tarif_5 | A TransJakarta fare increase is necessary to improve service quality. |
| tarif_6 | A TransJakarta fare increase should be accompanied by improved services. |
| tarif_7 | I believe that a fare increase will have a positive impact on service quality. |

## Variable 2: Users' Interest in Using TransJakarta
| Code | Statement |
|---|---|
| minat_1 | I will continue using TransJakarta even if the fare increases. |
| minat_2 | I will continue using TransJakarta regularly every week. |
| minat_3 | I would recommend TransJakarta to others even if the fare increases. |
| minat_4 | I am willing to adapt to changes in fares as long as the service remains good. |
| minat_5 | Despite having other transportation options, I will continue choosing TransJakarta because of its dedicated and congestion-free routes. |
