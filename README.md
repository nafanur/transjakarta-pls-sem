# TransJakarta PLS-SEM Analysis

## Research Objective
This project analyzes the relationship between acceptance of
TransJakarta fare increases and users' interest in continuing
to use TransJakarta using Partial Least Squares Structural
Equation Modeling (PLS-SEM).

## Methodology
- Data preprocessing: RStudio
- PLS-SEM estimation: RStudio and SmartPLS
- Bootstrapping for hypothesis testing
- Measurement model evaluation
- Structural model evaluation

## Model
Acceptance of TransJakarta Fare Increase → Interest in Using TransJakarta

## Results
### Measurement Model
All indicators achieved acceptable outer loadings.
Both constructs demonstrated satisfactory reliability
and convergent validity.
- Composite Reliability: 0.909–0.934
- AVE: 0.594–0.738

### Structural Model
- R² = 0.564
- Direct Effect = 0.751
- Hypothesis: Supported (p-value < 0.05)
The model explains 56.4% of the variance in users'
interest in using TransJakarta.
